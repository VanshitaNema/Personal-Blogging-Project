# Personal Blogging Platform

A full-stack web application designed for creating, managing, and sharing blog posts. Built with a responsive frontend and a robust Python backend, this project demonstrates foundational full-stack development skills and database management.

## 🚀 Features
* **Content Management (CRUD):** Users can seamlessly create, read, update, and delete blog posts.
* **Interactive Frontend:** A dynamic and responsive user interface built for optimal reading and navigation.
* **Data Persistence:** Reliable storage and retrieval of blog entries utilizing a relational SQL database.
* **Local Development Server:** Easily deployable on local environments using Flask's built-in server capabilities.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python (Flask)
* **Database:** SQL (SQLite via `database.db`)
